# NOVA - AI Productivity Platform

## Project Description
NOVA is a modern, responsive landing page for a fictional AI-powered productivity platform. It demonstrates advanced front-end development techniques, including responsive design, smooth scrolling, and dynamic state management.

## Technologies Used
* React (via Vite)
* Tailwind CSS (v3)
* Framer Motion (for animations)
* React Icons

## Features
* **Fully Responsive Design:** Adapts seamlessly from desktop to mobile screens.
* **Dynamic Interactions:** Includes an animated count-up statistics section and a testimonial carousel.
* **State Management:** Monthly/annual pricing toggle and an FAQ accordion that keeps only one item open at a time.
* **Accessible Navigation:** Sticky header with smooth scrolling and a mobile hamburger menu.

## Installation Instructions
To run this project locally:
1. Clone the repository: `git clone https://github.com/Balaji-v17/nova-landing.git`
2. Navigate to the directory: `cd nova-landing`
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`
